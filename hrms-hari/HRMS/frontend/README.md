# Hari HRMS - Frontend

This is the React-based frontend for the Hari Human Resource Management System, built using Vite, Vanilla CSS, and modern UI/UX principles.

## 🚀 Key Modules

### 1. Unified Employee Workspace
- **Dashboard:** Personalized overview with attendance stats, recent activities, and upcoming events.
- **Profile Management:** Secure editing of personal data, documents, and professional info.
- **Attendance & Leaves:** Modern visual calendar and automated leave approval workflow.

### 2. Administrative Command Center
- **Analytics:** Data-driven insights into headcounts, payroll costs, and workforce demographics.
- **User Management:** Granular role-based access controls for employees, HR, and Admins.
- **Asset Track:** Inventory management for company-issued hardware.

### 3. Financial & ERP Core
- **Payroll Admin:** Automated payroll cycles with bulk processing and dynamic payslip generation.
- **Tally Integration:** Full double-entry bookkeeping, ledgers, and live balance sheets.
- **Sales & Purchases:** Transactional workflows for vendor and client management.

### 4. Growth & Communication
- **LMS (Learning Management System):** Internal training portal with video lessons and interactive quizzes.
- **Internal Messenger:** Real-time chat with support for group channels and file sharing.
- **Recruitment & Onboarding:** Complete pipeline from job posting to new hire integration.

## 🎨 Tech Stack & Aesthetics
- **Core:** React 18, Vite.
- **Styling:** Custom Vanilla CSS with Theme Context (Dark/Light mode support).
- **Interactions:** Framer Motion for micro-animations, Toast notifications for real-time feedback.
- **Real-time:** Socket.io for live messaging and notifications.

## 🛠 Setup & Development
1. `npm install` to install dependencies.
2. `npm run dev` to start the development server.
3. Configure API endpoints in `.env` (refer to `.env.example`).
